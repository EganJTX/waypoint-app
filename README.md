# Waypoint

A local, single-user retirement tracker with an AI coach. Waypoint turns the accounts you already have into a simple, honest answer to one question: *am I headed in the right direction while there's still time to act?*

> **You have time. Let's use it.**

**Try it without installing anything:** open [`demo.html`](demo.html) in a browser. It's a self-contained walkthrough with a fictional persona (John Doe) and a real coach insight generated on his data. See [The demo](#the-demo) for what it can and can't do.

## What this is (and isn't)

Waypoint is **not** a financial advisor and doesn't give personalized investment advice. It's a calm dashboard that:

- tracks your retirement accounts ("vehicles") and logs periodic check-ins,
- projects where you're likely headed using a simulation (not a single guess),
- shows how that compares to the age and number *you* said you want, and
- optionally runs a **Coach**: a short written assessment with one or two suggestions, generated by the [Claude Code CLI](https://claude.com/product/claude-code) running on your own machine.

Everything except the Coach works without an AI. The Coach is optional.

## Setup

```bash
npm install
npm start
```

Then open `http://localhost:3003/waypoint-app`.

On first run, `config.json` doesn't exist yet. The server creates it from the committed `config.example.json` (an empty shell, no profile). Waypoint then walks you through a short setup interview: your name, birth date, target retirement age, the income you'd like in retirement, any Social Security or pension estimate, and a target number. After that, add your accounts on the **Data** tab and log a first check-in.

The Coach needs the `claude` CLI installed and signed in on your machine. Without it, everything else still works.

## How the projection works

- **Simulation, not a guess.** The chart shows the median of 250 simulated paths, plus a band for the middle 60% of outcomes. The simulation is seeded, so the same data always produces the same numbers.
- **Recomputed at check-in.** The projection is calculated when you log a check-in and then saved, so Waypoint can later compare what it predicted against what actually happened. Plain page loads don't recompute it.
- **Trajectory.** *Ahead*, *On Track*, or *Worth Review* is based on the age your projection first reaches your target number, compared with the retirement age you want. It's a prompt to look closer, not a verdict.
- **Every account has a Type.** You pick one on the Data tab, grouped under a parent category, with plain-language help for each. The Type decides how the projection treats the account. Here is the full table (it lives in one place, `js/vehicle-types.js`, and everything else reads from it, including the coach):

| Group | Type | Examples | How the projection treats it | Counts toward retirement |
|---|---|---|---|---|
| Investment | Investment account | 401k, IRA, brokerage | Market simulation (4–10% range you set) | Yes |
| Insurance | Life insurance: builds cash value | whole life, universal, paid-up | Contributions only, no growth | Yes |
| Insurance | Life insurance: protection only | term life | Left out of the projection | No |
| Checking/Savings | Checking | checking account | Contributions only, no growth | Yes |
| Checking/Savings | Savings | savings account, high-yield savings | Contributions only, no growth | Yes |
| Other | Other | — | Held at current balance | Yes |

- **A simplified model (v1).** Only Investment accounts grow at the market-rate range. Cash value insurance, savings and checking are carried forward with their contributions only, which is a steady straight line, because real caps and rates are unknown. Real accounts usually grow more, so the projection is conservative for them.
- **Protection-only insurance.** Term life is your family's safety net. It holds no cash value, its premium is a cost and not savings, and it's left out of the projection. Whole life and similar policies build cash value and are included.
- **Adding a new kind of account** (a 529 plan, an HSA, ...) means adding one row to the table in `js/vehicle-types.js`. Nothing else needs to change.

## Data and privacy

`config.json`, `data.json`, and `coachAnalyses.json` are gitignored. Once you fill them in with your real information, none of it is tracked by git or leaves your machine, with one exception: when you click **Run a new analysis**, the Coach sends your profile, your account balances and projection, your notes, and your recent analyses to Anthropic through the Claude Code CLI, under your own account. If you don't want that, don't use the Coach.

Beyond that, Waypoint is a small Express server (`server.js`) doing local file reads and writes. There's no database. The page loads Chart.js and web fonts from public CDNs.

`data.json` and `coachAnalyses.json` aren't bootstrapped from templates. They start empty and are created on first write.

## The demo

`demo.html` is a single file you can open directly. It contains:

- the real Waypoint interface, running entirely in your browser on fictional data (**John Doe**, 42, with a 401k, whole life, savings and a college fund),
- the same projection math as the real app, so the numbers and charts behave the same way,
- a real coach analysis, generated once by running the actual Coach on John's data and saved into the file.

What it **can't** do: **Run a new analysis does not work in the demo.** The Coach runs a real, local Claude Code analysis, which needs the full app running on your own machine. Clicking Run shows a message saying so. Edits you make in the demo (check-ins, settings) are kept only in your browser, and **Reset Demo Data to Original State** puts John back as he was.

To rebuild the demo after changing the app:

```bash
node scripts/build-demo.js
```

The build inlines the app's own `index.html`, CSS, and JavaScript and uses the fixtures in `demo-src/`. It never reads your real `config.json` or `data.json`.

## Project layout

| Path | What it is |
|---|---|
| `index.html`, `css/`, `js/app.js` | The interface (Presentation, Data, Configuration) |
| `js/vehicle-types.js` | The account types table: one place that defines how every kind of account is treated |
| `js/calculator.js` | The projection engine: simulation, percentiles, inflation |
| `server.js` | Local API and persistence |
| `scripts/coach-analyze.js`, `scripts/coach-shared.js` | The Coach: prompt, Claude CLI call, validation, history |
| `scripts/build-demo.js`, `demo-src/` | Builds `demo.html` from fictional fixtures |
| `docs/design-notes.md` | Ideas that are intentionally not built yet |
